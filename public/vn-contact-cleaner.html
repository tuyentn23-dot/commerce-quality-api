Vietnam phone and email normalization API

Normalize Vietnamese mobile numbers to +84 and check conservative email syntax in batches of up to 200 contacts. Try VN Contact Cleaner on RapidAPI.

Prepare contact data before a Vietnam CRM or order import. Submit 1–200 contacts in one HTTP request, up to 1 MB. Results preserve input order: results[i] describes contacts[i].

How Vietnamese mobile numbers are normalized

Accepted number shapes start with 0, +84, 0084 or bare 84. Spaces, parentheses, dots and hyphens are removed. A supported ten-digit local mobile shape such as 0912345678 becomes +84912345678. Landlines, extensions and old eleven-digit local numbers are unsupported.

Email case and invalid fields

The email domain is lowercased and IDN-encoded; local-part case is preserved. Outer whitespace is trimmed. Invalid supplied values return false validity and null normalized values; omitted values return null validity. This conservative ASCII local-part syntax check does not support every RFC email address.

A valid shape does not mean a number is allocated or reachable. This API does not verify mailboxes, deliverability, consent or ownership. Use a verification provider if you need live checks.

Request example

Set RAPIDAPI_KEY to your own consumer key. Copy the host from your RapidAPI playground if your subscription shows a different host. No provider secret is needed. This example uses a POSIX shell.

curl --request POST \
  --url 'https://vn-contact-cleaner.p.rapidapi.com/v1/contacts/normalize' \
  --header 'Content-Type: application/json' \
  --header "X-RapidAPI-Key: $RAPIDAPI_KEY" \
  --header 'X-RapidAPI-Host: vn-contact-cleaner.p.rapidapi.com' \
  --data '{"contacts":[{"email":"User@EXAMPLE.COM ","phone":"+84 912 345 678"},{"email":"bad-email","phone":"abc"},{}]}'

What if a request fails?

401: check your RapidAPI key and subscription; do not call the provider backend directly. 413: reduce the payload below 1 MB. 422: check required fields and batch limits. Timeouts can occur during free-hosting cold starts.
